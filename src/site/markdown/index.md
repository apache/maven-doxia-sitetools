# Doxia Sitetools

Doxia Sitetools is an extension of [base Doxia component](../doxia) that generates: **HTML sites**, adding site (header, footer, navigation bar, menu, ...) to content that was generated by Doxia: a site is defined in a **site skin**.

In addition, Doxia Sitetools processes files with extra `.vm` extension with [Velocity](http://velocity.apache.org/).
